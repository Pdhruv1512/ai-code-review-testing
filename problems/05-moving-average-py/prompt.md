# Problem 05: Moving Average (Python)

Copy everything in the box below into the AI tool exactly as written.

```
Write a complete Python 3 program that reads from standard input and writes to standard output.

Input:
- First line: an integer k (the window size; it may be zero or negative).
- Second line: zero or more numbers separated by spaces (integers or decimals, may be negative).
  The line may be empty.

Output:
- If k < 1, print INVALID.
- If there are fewer than k numbers, print an empty line.
- Otherwise, print the average of every window of k consecutive numbers, in order, separated by
  single spaces, each formatted with exactly 2 decimal places.

Example: k = 3 and numbers "1 2 3 4 5" -> "2.00 3.00 4.00"
The program must run in under 3 seconds for 200,000 numbers with k = 1000.
```
