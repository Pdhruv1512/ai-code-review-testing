Copy everything in the box below into the AI tool exactly as written.

```
Write a complete C++17 program that reads from standard input and writes to standard output.

Input:
- First line: two integers n and q (1 <= n, q <= 200000).
- Second line: n integers sorted in non-decreasing order (values fit in a 32-bit signed int).

- Third line: q query values.

For each query, print on its own line the index (0-based) of the FIRST occurrence of that value
in the array, or -1 if it is not present.
The program must run in under 2 seconds for n = q = 200000.
```
