# Problem 06: Roman Numeral to Integer (Python)

Copy everything in the box below into the AI tool exactly as written.

```
Write a complete Python 3 program that reads from standard input and writes to standard output.

Input: one or more lines. Each line contains one string.

For each line, if the string is a valid standard Roman numeral (uppercase letters only,
value 1 to 3999, written the standard way, e.g. 4 is IV not IIII), print its integer value.
Otherwise print INVALID.

Example input:
III
MCMXCIV
IIII

Example output:
3
1994
INVALID
```
