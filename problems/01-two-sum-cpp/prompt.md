# Problem 01: Two Sum (C++)

Copy everything in the box below into the AI tool exactly as written.

```
Write a complete C++17 program that reads from standard input and writes to standard output.

Input:
- First line: two integers n and target (0 <= n <= 100000, |target| <= 4 * 10^9).
- Second line: n integers a[0..n-1] (|a[i]| <= 2 * 10^9).

Find indices i < j such that a[i] + a[j] == target.
If more than one pair works, choose the pair with the smallest i; if there is still a tie, the smallest j.

Output: print "i j" (0-based), or "-1 -1" if no such pair exists.
The program must run in under 2 seconds for n = 100000.
```
