# Problem 07: Remove Duplicates, Case-Insensitive (Python)

Copy everything in the box below into the AI tool exactly as written.

```
Write a complete Python 3 program that reads lines from standard input and writes to standard output.

Each line contains one word or phrase. Remove duplicates and print the remaining lines in their
original order, keeping the FIRST occurrence of each.

Rules:
- Comparison is case-insensitive and must work for non-English letters too

- Ignore leading and trailing spaces when comparing, and print the stripped version.
- Skip blank lines (empty or only spaces).

The program must run in under 3 seconds for 200,000 lines.
```
