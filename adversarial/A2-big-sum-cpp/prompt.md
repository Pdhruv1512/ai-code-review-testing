# A2: Exact Sum of Large Numbers (C++)

**Trap being tested:** the sum can exceed the range of `long long` (about 9.22 × 10^18).

```
Write a complete C++17 program that reads from standard input and writes to standard output.

Input:
- First line: an integer n (1 <= n <= 10).
- Second line: n non-negative integers, each at most 10^18.

Print the exact sum of the n integers.
```
