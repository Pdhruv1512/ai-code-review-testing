# Problem 04: Reverse Words (C++)

Copy everything in the box below into the AI tool exactly as written.

```
Write a complete C++17 program that reads ONE line from standard input and writes to standard output.

The line contains words separated by one or more spaces. It may have leading or trailing spaces,
and it may be empty. A word is any run of non-space characters (punctuation stays part of the word).

Output the words in reverse order, separated by exactly one space, with no leading or trailing spaces.
If there are no words, print an empty line.
The line can be up to 2,000,000 characters long.
```
